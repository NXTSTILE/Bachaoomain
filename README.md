# Authentication Page 

This is a modern, responsive Authentication page built as a Next.js application, utilizing TypeScript and Tailwind CSS (Latest version). It is fully designed to deliver a high-quality visual user experience. 

## Technical Details:
- **Framework**: Next.js v15 (App Router Setup)
- **Styling**: Tailwind CSS v4 
- **Language**: TypeScript

## Quick Start 
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` with your browser to see the result.

## Functionality
This authentication page features four main inputs that form our signup structure properly styled using custom radio panels for selection.
1. **Registration Number**
2. **Full Name**
3. **Role (Helper vs Poster)**
4. **Password**
